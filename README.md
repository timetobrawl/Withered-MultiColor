# Withered-MultiColor
[Withered Utils](https://github.com/Seminosowo/Withered-Utils) with Optifine exclusive resource pack support. If your resource pack says needs optifine or a mod or a modpack, then it's most likely supported here!

# FAQ

| Question | Awnser|
|-----------------|-----------------|
| Is it pre configured? | No, all resource packs require different mod settings, so i can not make a universal one. You need to check yours and configure it accordingly. |
| Help! Custom chests and other tile entities are not working! | While [Better Block Entities (BBE)](https://modrinth.com/mod/better-block-entities) Optimizes tile entities, it also prevents custom models head over to Mods -> BBE and disable optimization of your tile entity. |
| Help! Custom item textures (CIT) are not working! | For items, this feature was added to vanilla in 1.21.5+, so update your resource pack. For armors and elytras, no cit mod that mimics optifine's cit is updated to the current modpack. Version tho there is [Variants-CIT](https://modrinth.com/mod/variants-cit) if possible ask your resource pack developer to support it.

Not helpful? Report an issue.
